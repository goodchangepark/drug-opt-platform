The live Help page is authoritative for installed versions and availability. It is generated by `/api/help/registry` and `/api/interpretation/rules` from the runtime package inventory, Model Registry, PK Method Registry, Capability Registry, and Centralized Scientific Interpretation Registry.

## Current workflow

Drug-OPT supports project-isolated compound registration and CompoundVersion history; standardized structures and calculated properties; experimental activity and SAR; installed ADMET, metabolism, transporter, and safety predictions; medicinal chemistry strategy and analog generation; experimental PK and NCA; IVIVE; IV, PO, SC, and IP simulation; cross-species scaling; human translational PK; prospective freezing; retrospective validation; and standardized scientific interpretation presentation.

Predictions and calculations are decision-support evidence. They do not replace experimental studies.

## UI/UX Scientific Presentation Architecture

1. **Deterministic Scientific Interpretation Engine (`backend/interpretation.py`)**:
   - Centralized, rule-based interpretation mapping raw values to standardized assessments (`FAVORABLE`, `INTERMEDIATE`, `LIABILITY`, `UNFAVORABLE`).
   - Strict 3-color semantic standard: **Blue** (Favorable), **Gray** (Intermediate/Uncertain), **Red** (Liability/Unfavorable).
   - Accompanying textual descriptions and guideline references (Lipinski Rule of 5, Veber Rule, Lovering Fsp3, Bickerton QED, FDA BCS, FDA DDI Guidance).

2. **Unified Scientific Typography & Design System (`frontend/static/app.css`)**:
   - Primary Korean/Latin typographic stack: `Noto Sans KR`, `Noto Sans CJK KR`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`.
   - Explicit visual hierarchy with clear numeric tabular alignment.
   - Qualitative developability normalized bar chart representation (`VisualProfileChart`).

3. **Compound Workspace Presentation (`frontend/static/app.js`)**:
   - **Header Card**: Molecular formula, molecular weight, copyable SMILES bar with 1-click clipboard button.
   - **Overview Tab**: Basic Property Summary grid with Lipinski/Veber badges + Executive ADMET Highlights cards.
   - **Properties Tab**: Unified Physicochemical Table (Property, Calculated Value, Drug-Likeness / Reference Range, Assessment), Structural Alerts, Henderson-Hasselbalch Ionization section, Experimental Physicochemical Data entry.
   - **ADMET Tab**: Unified Prediction Table with model provenance (M1/M2/Consensus), qualitative Visual Profile Chart, experimental concordance matrix, model governance collapse.
   - **Metabolism Tab**: Cross-species Microsomal Stability Table (Human, Rat, Mouse) with units & physiological context, CYP450 enzyme panel with Model Applicability chips (`IN DOMAIN`, `BORDERLINE`, `OUT OF DOMAIN`).
   - **PK Tab**: Multi-Species PK Summary Table (Mouse, Rat, Dog, Monkey, Human), IVIVE hepatic clearance, interactive multi-species concentration-time curves.

## Major limitations

- No full PBPK, PK/PD, or animal efficacy prediction.
- No qualified quantitative ML pKa model; the current estimate is rule-based.
- Several transporter and optional safety endpoints have no qualified local model.
- Conformal calibration is unavailable or undercovered for some operational models.
- Microsomal clearance confidence is LOW.
- Soft spots, metabolite hypotheses, and generated analogs require experimental validation.
