# Ketcher structure editor

This directory contains the Ketcher 3.5.0 standalone browser build distributed
by EPAM Systems from the official Ketcher download page.

- Source and release: https://github.com/epam/ketcher
- Official downloads: https://lifescience.opensource.epam.com/ketcher/downloads.html
- License: Apache License 2.0

Ketcher is served locally so drawing and SMILES synchronization do not send a
project compound structure to an external editor service.
